# What I Learned

## 1. Understanding Active Directory

Through this project, I developed a better understanding of how Active Directory is used to manage users and computers in a Windows environment.

I learned that Active Directory provides centralized identity management, allowing users to authenticate using domain accounts instead of relying only on local computer accounts.

I also learned the role of a Domain Controller and how it provides authentication services to domain-connected computers.

## 2. Understanding DNS in a Domain Environment

One of the most important concepts I learned was the relationship between DNS and Active Directory.

I learned that a client needs to locate a Domain Controller before it can successfully join a domain or authenticate against Active Directory.

This helped me understand why configuring the correct DNS server is an important step when troubleshooting domain join issues.

## 3. Managing User Accounts

I gained practical experience creating a domain user through Active Directory Users and Computers.

I learned how to:

- Create a user account.
- Configure the user logon name.
- Set an initial password.
- Enable or disable an account.
- Verify that an account exists in Active Directory.

These tasks are relevant to common help desk responsibilities such as onboarding users and assisting with account-related issues.

## 4. Joining a Windows Computer to a Domain

I learned how a Windows workstation becomes part of an Active Directory domain.

The process involved configuring the client network, pointing its DNS setting to the Domain Controller, and joining the computer to company.com.

I also learned that domain joining requires more than simply entering the domain name. The client must be able to locate and communicate with the Domain Controller.

## 5. Troubleshooting Methodology

This project helped me develop a more structured troubleshooting approach.

Instead of immediately changing settings, I learned to check:

1. Network configuration
2. Connectivity
3. DNS resolution
4. Domain membership
5. User account status
6. Authentication

This approach helps narrow down the source of an issue before applying a resolution.

## 6. Relevance to IT Support

The skills developed in this lab are relevant to an IT Support Technician or Help Desk Analyst role.

Examples of related tasks include:

- Creating and managing user accounts.
- Joining computers to a company domain.
- Troubleshooting domain login problems.
- Checking DNS and network connectivity.
- Verifying computer membership in Active Directory.
- Documenting technical issues and their resolutions.

## 7. Future Improvements

After completing this project, I plan to expand the environment with additional help desk scenarios.

Potential improvements include:

These improvements will help me develop a deeper understanding of Windows administration and enterprise IT support.
